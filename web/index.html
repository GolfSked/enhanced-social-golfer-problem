A FEW SIMPLE STEPS

Your golfers. Your courses.

  1. Choose your draw

    Open an explorer and select the number of golfers. Use Colour by to move between rounds; each colour corresponds to a tee time.

  2. Make it yours

    Expand Replace player numbers with names and enter one name per line. In Edit rounds, enter your course labels, first tee times and intervals, then apply your changes.

  3. Read the grid

    Each cell is a golfer. Rows give the first-round groups, columns the second-round groups. Matching numbers in partial squares A, B and C give the later groups. Empty cells are simply empty.

Set up a shareable link

Add names with players=Alice:Bob:Charlie:…, in player-number order. A list of 15–24 names selects that player count. Add one round= entry for each round, in order:

?round=Moruya|11:35&round=Narooma|10:00

A round is Course|HH:MM|interval. Leave off the interval to use seven minutes. Encode spaces as %20. The remaining rounds use the defaults. URL settings take precedence over saved settings when you reopen a link.

Names included in a URL are visible to recipients and may appear in hosting logs. You can instead enter them in the name editor. Browser edits do not change the URL or the published files.

MORE THAN A RANDOM SHUFFLE

A little mathematics.
A better mix.

Every golfer plays once per round, and no pair plays together twice. The groups favour fours, with triples filling the remainder; participation in fours differs by at most one between golfers.

Fairness first maximises the smallest number of distinct tee slots received by any golfer, then the total across everyone. It measures slot variety, rather than average start time. Editing tee times changes the clock labels, not that objective.
